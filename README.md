# Multi-Store Inventory Tracker

A lightweight Android app for tracking inventory across multiple stores, based on the workflow used in the supplied HTML inventory tracker.

## Features
- Store tabs for Master Summary and individual stores
- Master inventory summary with stock status and reorder alerts
- Add new master items
- Record stock received and issued transactions by store
- Persistent local SQLite database
- Dark-themed mobile UI

## Project setup
1. Open the project in Android Studio.
2. Let Gradle sync.
3. Run the app on an emulator or physical device.

## Notes
This app is designed to mirror the inventory management workflow from the sample tracker but implemented as an Android app using Kotlin and SQLite.
